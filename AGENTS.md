# AGENTS.md

Instructions for AI coding agents working in this repository. Start with [README.md](README.md).

## Adding words

- Never add a term the support docs ask writers to avoid (the "Not" column in
  [Names and terms](https://github.com/nesi/support-docs/blob/main/docs/FORMAT.md#names-and-terms),
  such as `MyNeSI`, `GiB`, `OTP`, `hyperthreading`). Leaving it out of the dictionary is what makes the spellcheck flag it.
  Reword the docs to the preferred term instead.
